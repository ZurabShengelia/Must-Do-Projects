# NoteTaker

NoteTaker is a note-taking app that runs entirely in your browser. You write entries, sort them into categories, bookmark the ones you want at the top, and everything is saved on your own device. There is no server, no account and no network traffic. It is built with HTML, CSS and vanilla JavaScript (ES modules), and it has a Victorian library look: a leather index, parchment pages, a light theme and a dark one.

## Features

- Create, edit and delete entries. Deleting asks for confirmation.
- Five categories (General, Personal, Work, Learning, Ideas), with counts in the index.
- Bookmark entries; bookmarked entries are listed first, then the rest by most recent change.
- Search across titles and text.
- Automatic saving about 0.6 seconds after you stop typing, with a visible state: unsaved, saving, saved.
- "Written" and "Amended" dates on every entry.
- Copy an entry's text with one button.
- Light and dark themes. The choice is remembered; the system setting is used the first time.
- Prints only the open entry, on parchment colours, whichever theme is active.
- English and Georgian text on the same lines (Georgian uses a font installed on your device).
- Responsive: index and two pages on desktop, a top bar above the book on tablets, one pane at a time on phones.
- Keyboard shortcuts (press `?` to see them): `Alt+N` new entry, `Ctrl/Cmd+K` search, `Ctrl/Cmd+S` save now, `Alt+B` bookmark, `Up` and `Down` through the list.
- Respects `prefers-reduced-motion`.

Limits: a title holds up to 120 characters and an entry up to 20,000.

## Technology

HTML5, CSS3 and JavaScript ES modules, with no framework, no build step and no runtime dependencies. Data is kept in `localStorage`. Fonts are bundled with the project.

## Project structure

```

js/storage.js         LocalStorage load and save
js/search.js          text search
js/view.js            category filtering and view reset rules
assets/fonts/         bundled Latin fonts and their licences (assets/fonts/LICENSES/)
assets/favicon.svg    the app icon
tests/                unit tests (Node's built-in test runner)
scripts/              optional browser checks and tooling (Python)
docs/                 design brief, font documentation, product scope
```

## Run it

You need a static web server. Opening `index.html` directly from the file system does not work, because browsers block ES modules and fonts loaded from `file://`.

With Python 3, from the project folder:

```
npm start
```

or, without npm, `python3 -m http.server 8080`. Then open <http://localhost:8080>. Any other static server works as well. Once the page has loaded, the app needs no network connection.

## Tests

The unit tests cover the note model, storage, search and view logic, and scan the scripts for unsafe DOM sinks such as `innerHTML` and `eval`. They use Node's built-in test runner and have no dependencies. They were run with Node.js 22.

```
npm test
```

### Browser checks (optional)

Two scripts drive a real browser against the app, and a third prints palette contrast ratios. They need Python 3 and are not part of the app:

```
pip install playwright
playwright install chromium
python3 scripts/contrast.py       # contrast ratios of the colour palette
python3 scripts/check_app.py      # create, edit, delete, search, bookmark, persistence, print, keyboard, themes
python3 scripts/check_motion.py   # layouts at seven widths in both themes, contrast, focus, animation, fonts
```

They run 47 and 100 checks, including text contrast measured from computed styles, a 2px focus ring on every Tab stop, no horizontal overflow, reduced-motion behaviour, and that every request stays on the local origin. The print check writes one PDF to the system temporary folder, not to the repository. These checks are not an accessibility audit.

## How your notes are stored

Entries are saved as one JSON document in your browser's `localStorage`, under the key `notetaker-notes`. The only other thing stored is your theme choice (`notetaker-theme`). On load, every record is validated and invalid ones are skipped with a message.

## Privacy

- Your entries never leave your device. The app makes no requests to other sites and has no analytics or tracking. The Content Security Policy in `index.html` blocks outside connections, scripts and fonts.
- Entry text is only ever written to the page as text, never as HTML.
- `localStorage` is **not encrypted**. Anyone who can use your browser profile can read your entries, and browser extensions with access to the site may be able to as well.
- Clearing the site's data in the browser deletes your entries. There is no sync between devices and no export, so back up anything important yourself.
- Browsers limit `localStorage` to a few megabytes per site. The app reports when storage is full.

## Browser support

The app and its checks were run in Chromium 153 only. It uses `<dialog>`, `clip-path`, CSS `size-adjust` and the Clipboard API, which current Firefox and Safari also provide, but they have not been tested here.

## Limitations

- Entries live in one browser on one device.
- There is no export, import or sync.
- Georgian letters depend on fonts installed on the device. See `docs/FONTS.md`.
